Build of NewGunrizons for **GTNH 2.9.0** (stable).

Drop the jar into the `mods` folder of a GTNH 2.9.0 instance (client and server).

### Changes
- Dependencies moved to the GTNH 2.9.0 manifest: GTNHLib 0.11.54, NotEnoughItems 2.8.171-GTNH, Angelica 2.2.43 (test), GregTech 5.09.54.265 (compile-only).
- GregTech Assembler recipes for every current item: 12 Gauge Shotgun Shell (LV), Doom Shotgun (MV), Plasma Rifle (EV), Laser Rifle (IV). Registered only when GregTech is present.
- New "NewGunrizons: Arsenal" BetterQuesting quest line in `quests/`, with install scripts for Windows and Linux.

### Known limitations
- Only 3 weapons have been migrated to the Bedrock model system so far.
- Plasma and Laser Rifles use 12 Gauge shells until energy cells are added.
