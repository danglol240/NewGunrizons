NewGunrizons **1.0.1** ported to **GTNH 2.9.0-RC-2**.

Drop the attached jar into the `mods` folder of a 2.9.0-RC-2 instance (remove any older NewGunrizons jar first).

### Contents
- The full upstream 1.0.1 weapon set (~100 firearms), attachments, magazines, ammo and grenades
- GregTech crafting: Assembler and Forming Press recipes, LV → IV

### Changes from upstream 1.0.1 (GTNH 2.8.4)
- GT5-Unofficial 5.09.51.482 → 5.09.54.205
- GTNHLib 0.7.10 → 0.11.52
- NotEnoughItems 2.8.44-GTNH → 2.8.155-GTNH
- Built against Angelica 2.2.28
- `Materials.Plastic` → `Materials.Polyethylene` (renamed in GT5)
