First build of NewGunrizons for **GTNH 2.9.0-RC-2**.

Drop the attached jar into the `mods` folder of a 2.9.0-RC-2 instance.

### Changes from upstream (GTNH 2.8.4 build)
- GTNHLib 0.7.10 → 0.11.52
- NotEnoughItems 2.8.44-GTNH → 2.8.155-GTNH
- Tested against Angelica 2.2.28 (shader pipeline)
- Code formatting brought in line with the GTNH spotless rules

### Known limitations
- No crafting recipes yet: weapons, attachments and ammo are only available from the creative tab. GregTech recipes (LV → UHV) are planned for the next version.
