# NewGunrizons quest line (BetterQuesting, GTNH)

Generated by `tools/gen_quests.py`.

## Install on a server (or in single player)

1. Copy the two folders `QuestLines/NewGunrizonsArms-...` and `Quests/NewGunrizonsArms-...` into
   `config/betterquesting/DefaultQuests/QuestLines/` and `config/betterquesting/DefaultQuests/Quests/`.
2. Append the line in `QuestLinesOrder-append.txt` to `config/betterquesting/DefaultQuests/QuestLinesOrder.txt`.
3. Start the server. As an operator, run `/bq_admin default load`.

Player progress is kept. The quests expect the Munitions Factory at MetaTileEntity ID 17920 and the Drone Assembly Bay
at 17921, which are the defaults in `newgunrizons.cfg`.
