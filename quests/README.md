# Quest lines (BetterQuesting, GTNH 2.9)

Two quest lines, generated by scripts in `tools/`:

| Folder | Quest line | Generator |
|---|---|---|
| `DefaultQuests/` | **NewGunrizons**: 70 quests, weapons, Munitions Factory, drones | `tools/gen_quests.py` |
| `TwistSpaceTechnology/DefaultQuests/` | **Twist Space Tech Guide**: 111 quests for the Twist Space Technology mod (TST 0.8) | `tools/gen_tst_quests.py` |

The `questbook` branch has both laid out as a ready-to-copy `config` folder.

## Install (server or single player)

1. Copy the `QuestLines/<folder>` and `Quests/<folder>` folders of each quest line into
   `config/betterquesting/DefaultQuests/QuestLines/` and `config/betterquesting/DefaultQuests/Quests/`.
2. Append the line in each `QuestLinesOrder-append.txt` to `config/betterquesting/DefaultQuests/QuestLinesOrder.txt`.
3. Start the server. As an operator, run `/bq_admin default load`.

Player progress is kept. The NewGunrizons quests expect the Munitions Factory at MetaTileEntity ID 17920 and the Drone
Assembly Complex at 17921, the defaults in `newgunrizons.cfg`.

## The TST guide

`tools/extract_tst.py` reads the TST source (machine IDs, names, tooltips, hatches, structure blocks, controller
recipes) into `tools/data/tst_machines.json`; `tools/gen_tst_quests.py` turns that into quests. To update for a new TST
release: `python3 tools/extract_tst.py <TST checkout> tools/data/tst_machines.json && python3 tools/gen_tst_quests.py .`

Each machine quest gives the full tooltip, the hatches, the structure's special blocks (as an optional task) and every
ingredient of the controller recipe. Inspired by Aditya's TST quest book (github.com/AdityaVG13/Twist-Stuff); it can be
installed next to it, since the quest lines have different IDs.
