# NewGunrizons quest book (BetterQuesting, GTNH 2.9)

English quest line "NewGunrizons": 70 quests in a grid, one column per tier (LV to MAX). Each column runs
factory era → components → weapon → Drone Assembly Complex storey → drone.

Generated by `tools/gen_quests.py` on the `high-tier-guns` branch; do not edit by hand.

## Install (server or single player)

1. Copy the `config` folder of this branch over the instance's `config` folder (it only adds
   `config/betterquesting/DefaultQuests/QuestLines/NewGunrizons-…` and `…/Quests/NewGunrizons-…`).
2. Append the line in `QuestLinesOrder-append.txt` to `config/betterquesting/DefaultQuests/QuestLinesOrder.txt`.
3. Start the game or server and, as an operator, run `/bq_admin default load`.

Player progress is kept. If you installed an earlier version, delete its `NewGunrizonsArms-…` folders first.
The quests expect the Munitions Factory at MetaTileEntity ID 17920 and the Drone Assembly Complex at 17921
(the defaults in `newgunrizons.cfg`).
