# Quest books for GTNH 2.9 (BetterQuesting)

Two quest lines, ready to copy into an instance:

- **NewGunrizons**: 70 quests, weapons LV to MAX, the Munitions Factory, drones and the Drone Assembly Complex.
- **Twist Space Tech Guide**: 111 quests for Twist Space Technology (TST 0.8). Every multiblock, hatch and module,
  one column per tier (Steam to MAX). Each machine quest has the full tooltip, the hatches, the structure's special
  blocks as an optional checklist, and every ingredient of the controller recipe. It can sit next to Aditya's TST quest
  book: the quest lines have different IDs.

Generated by `tools/gen_quests.py` and `tools/gen_tst_quests.py` on the `high-tier-guns` branch; do not edit by hand.

## Install (server or single player)

1. Copy the `config` folder of this branch over the instance's `config` folder. It only adds the folders
   `config/betterquesting/DefaultQuests/QuestLines/{NewGunrizons-…,TwistSpaceTechGu-…}` and the same two under `Quests/`.
   Only install the quest lines for mods you have.
2. Append the lines of `QuestLinesOrder-append.txt` to `config/betterquesting/DefaultQuests/QuestLinesOrder.txt`
   (if a line with the same ID is already there, replace it).
3. Start the game or server and, as an operator, run `/bq_admin default load`.

Player progress is kept. If you installed an earlier NewGunrizons version, delete its `NewGunrizonsArms-…` folders first.
The NewGunrizons quests expect the Munitions Factory at MetaTileEntity ID 17920 and the Drone Assembly Complex at 17921
(the defaults in `newgunrizons.cfg`).
